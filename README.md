# ST APP

Minimaler Web-RTS-Prototyp (TypeScript + Vite)

## Lokales Entwickeln

Installiere Abhängigkeiten und starte den Dev-Server:

```bash
npm install
npm run dev
```

Dann `http://localhost:5173` im Browser öffnen.

## Ziele

- Einfache Canvas-RTS-Mechanik
- Klick, um Einheiten zu bewegen
- Grid und placeholder-Grafiken
